# Python Functions

This folder contains Python practice programs focused on functions and their related concepts. It includes basic function exercises, problem-solving tasks, and advanced function techniques.

## Topics Covered

### 1. Functions Fundamentals
- Defining and calling functions
- Function parameters and arguments
- Returning values
- Functions with multiple arguments
- Nested function calls
- Higher-order functions

### 2. Lambda Functions
- Creating anonymous functions using `lambda`
- Lambda with `map()`
- Lambda with `filter()`
- Lambda with sorting
- Lambda expressions for data transformation

### 3. Recursion
- Understanding recursive function calls
- Base conditions and recursive cases
- Factorial and Fibonacci series
- Sum of numbers and digits
- Reversing numbers and strings
- Palindrome checking
- Recursive searching
- Working with nested lists

### 4. Closures
- Understanding nested functions and closures
- Maintaining state using closures
- Independent memory in closures
- Using `__closure__` to inspect closure variables
- Practical examples such as counters, loggers and trackers

### 5. Decorators
- Understanding decorators
- Applying decorators to functions
- Decorators with arguments
- Chaining multiple decorators
- Preserving function metadata
- Practical examples such as authentication, logging and execution-time measurement

### 6. Generators
- Creating generator functions using `yield`
- Understanding generator execution flow
- Iterating through generated values
- Handling `StopIteration`
- Sending values to generators using `send()`
- Infinite generators
- Generator expressions
- Generators vs lists

# Python Basics
This folder contains my Python fundamentals practice, including basic programming concepts, problem-solving exercises, and logical challenges.
The purpose of this folder is to strengthen my understanding of Python syntax, data structures, control flow, and problem-solving.

## Topics Covered
### 1. Python Fundamentals
- Variables and data types
- Operators and expressions
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Nested loops

### 2. Strings
- String manipulation
- String formatting and alignment
- String slicing and methods
- Palindrome and anagram problems
- Character and word-based problems

### 3. Lists, Tuples and Sets
- List operations and methods
- Nested lists
- Tuple operations and manipulation
- Set operations
- Removing duplicates
- Finding combinations and subsets

### 4. Problem Solving
- Number-based problems
- Prime and Armstrong numbers
- Factorial and palindrome problems
- Mathematical calculations
- Pattern printing
- Matrix operations
- Sorting and searching-related exercises

### 5. Other Practice
- Lambda expressions
- Nested functions
- Generators
- Decorators
- Exception handling

## Practice Approach
The folder contains individual Python programs and exercises written while learning and practising different concepts.
Each file focuses on a particular problem or concept.

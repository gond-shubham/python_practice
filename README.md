# Python Practice

This repository contains my Python learning journey, practice programs, exercises and mini-projects.

The main goal is to strengthen my Python fundamentals, improve problem-solving skills and gain practical experience with Python concepts that are useful for Data Science and AI.

## Repository Structure

| Folder | Description |
|---|---|
| **basics** | Python fundamentals, data types, operators, loops, strings, lists and problem-solving exercises. |
| **dictionaries** | Dictionary operations, nested dictionaries, dictionary transformations and dictionary-based problems. |
| **db_api** | Database connectivity and operations using Python's SQLite3 module, including CRUD operations, transactions and exception handling. |
| **datetime** | Working with dates, times, datetime objects, formatting, parsing and timedelta operations. |
| **file_handling** | Text file operations, CSV and JSON handling, data validation and file-related exception handling. |
| **functions** | Functions, lambda expressions, recursion, closures, decorators and generators. |
| **oop** | Object-oriented programming concepts, including classes, inheritance, encapsulation, abstraction, polymorphism and composition. |
| **regular_expressions** | Regular expressions using Python's `re` module for pattern matching, validation, extraction and text processing. |

## Learning Approach

- Learn Python concepts through practical examples.
- Solve problems to strengthen logical thinking.
- Practise file handling and structured data processing.
- Understand database operations using Python.
- Build small projects to apply learned concepts.
- Organise practice programs topic-wise for easy reference.

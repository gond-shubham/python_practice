# Python Datetime Module

This folder contains Python practice programs focused on working with dates, times and date-time calculations using Python's built-in `datetime` module.

The purpose is to understand how to represent dates and times, format and parse date strings, and perform date and time calculations.

## Topics Covered

### 1. Date
- Creating date objects using `date()`
- Getting the current date using `date.today()`
- Accessing year, month and day attributes
- Understanding the `date` data type

### 2. Time
- Creating time objects using `time()`
- Accessing hour, minute, second and microsecond
- Understanding the `time` data type

### 3. Datetime
- Creating datetime objects using `datetime()`
- Getting the current date and time using `datetime.now()`
- Accessing date and time attributes
- Extracting date and time separately using `date()` and `time()`
- Understanding the difference between `date` and `datetime`

### 4. Date and Time Formatting
- Formatting datetime objects using `strftime()`
- Converting datetime objects into strings
- Understanding format codes
- Parsing date strings using `strptime()`
- Converting strings into datetime objects
- Working with different date and time formats

### 5. Timedelta Operations
- Understanding the `timedelta` class
- Adding days and hours to dates
- Subtracting days from dates
- Calculating the difference between two dates
- Accessing the difference in days

### 6. Practical Exercises
- Filtering transactions based on a cutoff date
- Calculating the number of days between a record date and the current date
- Comparing dates
- Performing date-based calculations

## Practice Approach

The programs in this folder demonstrate how Python handles date and time data and performs date-based calculations.

The focus is on understanding date and time objects, string conversion, formatting and date arithmetic.

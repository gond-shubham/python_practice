# Python File Handling

This folder contains Python practice programs focused on reading, writing, processing and managing data stored in files.

The practice includes text files, CSV files, JSON files and handling common file-related errors.

## Topics Covered

### 1. Text File Handling
- Opening and closing files
- Reading and writing files
- Using `with` statement
- Reading complete file contents using `read()`
- Reading lines from files
- Counting lines, words and characters
- Working with file modes (`r`, `w`)

### 2. CSV File Handling
- Working with the `csv` module
- Reading CSV files using `csv.reader()`
- Writing CSV files using `csv.writer()`
- Reading records using `csv.DictReader()`
- Writing records using `csv.DictWriter()`
- Handling headers and rows
- Processing CSV data
- Performing basic data analysis on CSV files

### 3. JSON File Handling
- Understanding JSON data format
- Working with the `json` module
- Reading JSON files using `json.load()`
- Writing JSON files using `json.dump()`
- Handling lists and dictionaries in JSON
- Working with nested JSON structures
- Creating reusable JSON loading and saving functions

### 4. Data Validation
- Validating JSON data
- Checking required fields
- Detecting duplicate IDs
- Validating age and marks
- Handling missing keys

### 5. Exception Handling in File Operations
- FileNotFoundError
- JSONDecodeError
- OSError
- TypeError
- ValueError
- Handling invalid JSON formats
- Handling missing files
- Creating safer file loading and saving functions

### 6. Practical Exercises
- Counting lines, words and characters
- Reading and writing student records
- Managing employee records using CSV
- Storing restaurant and menu information using JSON
- Validating student records
- Analysing product sales and revenue from CSV data

## Practice Approach

The programs in this folder demonstrate how Python handles file operations and processes structured data.

The focus is on understanding file operations, data storage, data validation and error handling.

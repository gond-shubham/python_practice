# Object-Oriented Programming (OOP) in Python

This folder contains Python practice notebooks focused on Object-Oriented Programming (OOP). It covers fundamental OOP concepts, advanced class features, and practical examples.

The purpose is to understand how Python classes and objects work and how OOP concepts are used to organise and manage code.

## Practice Approach

The notebooks contain explanations, code examples and practical exercises for understanding OOP concepts.
